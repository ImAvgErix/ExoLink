# Exocord Windows alpha 0.1.12

This is a desktop-only UI hotfix cut from `d4cafc63ff67b2e3404b034e4102c591ff480cd0`.
The API protocol is unchanged; the live API remains `alpha-0.1.11-660ef6e0c5ce`
at `https://api-193-122-221-77.sslip.io`, with voice at
`wss://voice-129-153-173-234.sslip.io`. No server image was built or deployed
for this release.

The hotfix removes the click-blocking presence overlay, restores persisted
collapsible grouped workspace navigation, uses the canonical glass shell and
solid conversation surface, removes duplicate CSS, persists the DM-home
snapshot, tightens compact/responsive bounds, and keeps accessibility, focus,
and reduced-motion behavior intact. It does not add shortcut UI.
