# Exocord Windows alpha 0.1.13

This is the published desktop-only alpha cut from `135833f` (the reviewed
no-sidebar and refractive-glass redesign). The API protocol is unchanged; the
live API remains `alpha-0.1.11-660ef6e0c5ce` at
`https://api-193-122-221-77.sslip.io`, with voice at
`wss://voice-129-153-173-234.sslip.io`. No server image was built or deployed
for this release. The public update manifest at
`https://api-193-122-221-77.sslip.io/downloads/latest.json` reports version
`0.1.13`.

The release uses a real WebGL2 refraction layer for bounded glass surfaces,
with explicit renderer diagnostics and honest CSS/solid fallbacks. It carries
the compact no-sidebar shell and responsive voice dock, keeps the no-desktop-
shortcut installer policy while retaining the Start Menu shortcut, and adds a
persisted refractive-glass appearance setting with explicit accessibility
fallbacks. Reduced transparency, reduced motion, forced-colors, focus, and
screen-reader behavior remain accessible.

Published verification:

- The live `?refractiveGlass=proof` check rendered `WEBGL2 · 2 PLANES`.
- Installed-build checks covered signed-in session restore, singleton launch,
  close/reopen restore, and the absence of a desktop shortcut while retaining
  the Start Menu shortcut.
- System, Refractive, and Solid appearance modes changed live and persisted.
